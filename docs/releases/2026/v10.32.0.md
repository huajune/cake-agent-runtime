## 2. 范围与风险

### 变更摘要

- 地理确权链路支持同轮 geocode、城市确认问答和统一区名映射；全国县级市映射已生成化，但生产灰度开关缺省关闭。
- “店员 / 员工”等泛称不再作为精确岗位类目过滤，避免把真实在招的收银、理货、促销等岗位查成空。
- 学生身份首写增加证据门，出站守卫禁止教唆候选人改填社会人士；残障身份主动披露改为确定性静默转人工。
- 无岗位证据时禁止断言具体发薪时点；裸钟点动身也必须重新做预约 precheck；建单成功后的回复必须与预约回执一致。
- 复聊增加候选人待答前置闸、已处理水位、带外工单核验和“连续无回应”冷却语义，降低丢 turn 后继续提醒或错误复聊的风险。
- `tool_call` 事件补 `errorType / apiCode`；AMAP 配额/密钥业务失败进入结构化监控；面试取消人工介入卡升级为红色紧急提醒。

### 高风险区域

- **P0：身份与合规**——错误放行会教唆身份虚报，或对残障候选人自动筛选、拒绝。
- **P0：预约事实**——漏 precheck 会沿用过期截止时间；建单后错误追问会让候选人误以为预约尚未提交。
- **P0：复聊投递**——候选人消息被静默丢弃后继续提醒会造成二次伤害；冷却过严会漏掉已重新进入流程的候选人。
- **P0：岗位与城市召回**——泛化类目或错误城市证据会把真实岗位过滤为空，或把候选人路由到错误城市。
- **P1：外部依赖与观测**——AMAP 当前账号日配额探针返回 `10044`；缓存与行政区兜底仍可工作，但新地点解析可能降级，发布后必须观察结构化告警。
