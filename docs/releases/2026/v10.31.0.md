## 2. 范围与风险

### 变更摘要

- 修复城市同名品牌、履历品牌、定位分享和助手回声对 `currentBrand` 的污染，补齐鄂尔多斯东胜行政区映射。
- 将 geocode 唯一解析与定位分享逆地理解析沉淀为带来源的城市事实，并要求历史档案展示时披露来源、请候选人确认。
- 修复有证约岗位对明确无证候选人的策略解析与预约前置拦截；为测试链路 booking / cancel / modify 增加生产 PII 写入隔离闸门。
- 修复查无岗位时无证据断言结算周期的问题；收紧刚性时段、发薪合规、改期转人工、已拒条件和城市门口径。
- 将 Guardrail repair 改为默认 observe、白名单发牌，物理退役 replan 执行路径，并补齐双环质量体系文档与回归契约。

### 高风险区域

- **P0：品牌与城市事实**——地名被识别为品牌、履历覆盖求职品牌，或工具确权城市未入档，会导致跨城查岗、重复追问或错误拉群。
- **P0：预约与生产隔离**——证件门槛漏拦或测试手机号进入生产写工具，可能产生不合规预约或真实工单。
- **P0：岗位事实与结算口径**——岗位查询无数据时补写“日结/月结”等内容，会向候选人发送无依据的关键用工事实。
- **P0：出站守卫**——repair/replan 若重写正确事实、承诺或工具结论，可能把原始正确回复变成已投递伤害。
- **P1：行为类提示与召回边界**——刚性时段、发薪合规、改期转人工和已拒条件仍需在发布后按日报观察模型采纳与真实流量表现。
