## 2. 范围与风险

### 变更摘要

- 消息处理流水的 Agent 响应改用 `agentSteps` 还原真实多步执行顺序，不再把所有工具调用堆到最终文案前。
- 每一步固定按“思考过程 → 本步工具调用”展示，最终候选人可见文案使用权威 `reply.content` 并固定放在时间线末尾。
- 兼容没有 `agentSteps` 的历史记录：保留 reasoning / tool 过程，但剥离 AI SDK `response.messages` 中不可靠的 text 顺序，避免展示被守卫替换的首稿。

### 高风险区域

- P0：不能改变候选人真实投递内容；本次仅修改 Dashboard 的观测展示。
- P0：最终文案必须使用实际下发的权威回复，不能回退到模型原始首稿。
- P0：多步工具链必须保持 step 顺序，不能再次把工具与对应思考拆散。
- P1：历史记录可能缺少 `agentSteps`、`reply.content` 或完整工具结果，需要保持可读降级。
