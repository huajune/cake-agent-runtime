#### 💬 报名与收资（本周主体，08-27 起生效）

- 收资改由**确定性状态机**接管：必填项一次收全、筛选项优先发问；同一托管账号内换岗位不再重复盘问已经答过的资料。
- **社保这一格终于能填上了**——候选人答「无 / 没交过社保」以前逐字对不上系统选项被直接丢弃（上线前 3 天里这一格仅 1 次成功落格），现在能正确落格。
- **候选人答对了却被系统读不懂，不再算作「没答」**：不消耗「问两次就转人工」的配额；第一次读不懂会把全部可选项列出来重问，连续两次读不懂才转人工，且招募经理能看到真实原因。
- 候选人报「93 年」，系统换算成 33 岁不再被当成编造而拒收；资料被退回时 Agent 现在知道**退回原因和具体哪一格**，不再原样重投或把同一个问题再问一遍。
- **重复确认已消除**：一次填满整表、或明确说「都填好了」的候选人不再被要求核对两遍；「行」「妥」「没问题」「嗯嗯可以」这类口语确认现在算数（此前只认「确定」等少数词，回「行」会卡住整个流程）。
- **面试时间和资料现在可以同一轮一起收**，不必先填完资料再选时间；换岗位不会继承上一个岗位的时间，时段失效会及时提示重选。
- 年龄等硬性条件不符时走「明确告知不符 + 推荐其他岗位」，不再被误判成转人工。
- 「没有健康证」曾被记成「有健康证」，已修；疑似一人代多人报名时姓名手机号不写入表单，直接转人工。
- 效果初显：收资熔断导致的转人工从周二 17 次降到周五 **1 次**（周一 6 / 周二 17 / 周三 12 / 周四 7 / 周五 1）。样本只有一天，下周继续盯。

#### 🔧 出站守卫

- **移除了第二道 LLM 语义审查**，出站审查收敛到能与工具执行结果逐条对账的确定性规则。改写量从上周 101 条降到 **32 条**，拦截 9 条降到 **6 条**。
- 修了一个会让候选人**整轮收不到任何回复**的缺陷：首版回复被判违规、改写版其实合格，却被结构比对误判成「改坏了」而两版都不发。
- 班次时段承诺的判定收窄到同一句话内，并豁免否定/复述语境——此前 Agent 诚实说「这个班次排不了」也会被拦。
- 「已经帮你提交了」这类假回执继续拦；但预约失败后说「稍后再帮你提交」是合法承接话术，不再拦——此前会被改写成「这次没有提交成功，预约没约上」的劝退话术。
- 新增哨兵：Agent 宣称预约成功但实际没有提交工单时会被记录，便于对账。

#### 🌆 位置、岗位与拉群

- 修复**经纬度对调导致的假「无岗」**——命中的会话一律返回空岗位列表，此前 7 天内出现 4 例。
- 拉群口径按 0820 运营裁定收口：推荐不超过 2 轮、确认真无岗才拉群、拉群即收口；未经候选人两轮同意不再直接拉群。
- Agent 把内部分析当成回复发给候选人的问题，已在投递前确定性剥离。
- 修复静默窗口与锁重检两处会让候选人消息被静默丢弃的漏口。
- 隐私口径：候选人信息**不跨托管账号共享**。
