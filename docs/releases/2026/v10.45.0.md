## 2. 范围与风险

### 变更摘要

- **收资/预约主链路切换**：将表单字段映射、候选人自述提案、敏感项筛选、复述确认与写入收口到 collection/resolution 合同；预约继续以 precheck 与 booking 成功回执为唯一行为依据。
- **记忆 S1-S7 闭集**：会话事实、长期画像、阶段过程、岗位焦点与三态偏好在单一读写边界内进化；不把 chatHistory 当作持久化状态的替代品。
- **已退役链路删除**：清理旧收资/记忆分支及其死导出，CI 增加退役路径和开集合枚举断言。
- **三项独立侧线修复**：剔除内部推理泄漏；修复静默窗口/锁重检下的丢消息；收紧两轮岗位推荐失败后的入群授权协议。
- **58 条生产 BadCase 复测**：对 2026-08-06—2026-08-20 范围内冻结的精确 58 条待分析记录完成脱敏策展、测试集/验证集幂等导入、全量重放和逐条 Claude 评审；其中 50 条仍存在的飞书记录已回写，8 条源记录在回写时已从整个多维表格应用消失，保留为发布阻断。
- **重放中新发现的诚信闸门**：将 `booking_promise_without_booking` 从观测升为窄词形改写，无成功 booking/ready-to-book 时不再放行“马上提交”或“同事后台直接提交”。

### 高风险区域

- **P0｜收资和预约边界切换**：风险为重复收集、错字段写入、筛选后仍预约或无 booking 成功却声称已提交。防线为闭集表单合同、precheck/booking 凭据和两层出站 guardrail。
- **P0｜记忆语义迁移**：风险为三态偏好在“未知/明确值/明确清除”之间丢失否定语义，或跨用户/跨会话泄漏。防线为字段级合并规则、scope 隔离和 S1-S7 专项回归。
- **P1｜入群时机**：仅允许预约成功后承接，或两轮具体推荐均被否定后“先征询、下一轮明确同意再拉群”；风险为模型越过授权。
- **P1｜保护规则改写**：未落地预约承诺升为 revise。已为征询句、有前置收资条件和明确否定表达添加假阳性豁免。
