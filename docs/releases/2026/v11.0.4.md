## 2. 范围与风险

### 变更摘要

- 固化 v11.0.3 发版底账 + 失败路径守卫回归用例（PR #1081）

### 高风险区域

- **收资熔断记账语义变化**（PR #1086）：真实作答被词表/形态门拒收不再消耗发问配额，
  新增槽位账 `rejectedAttempts`（连续 2 次读不懂 → 新熔断原因 `unparseable_answer`）、
  disqualified 存在时可恢复熔断让位（`escalation_yielded`）。风险方向是"熔断变松 →
  同槽重问增多"；护栏：作答判定要求公证出处门已过（臆造提案不豁免）、读不懂两次仍转人工。
  观测：`collection_form_audit` 事件（`unparseable_answer` / `escalation_yielded` /
  `proposal_rejected`）与 handoff 率。
- 存量 Redis 收资表单新增可选字段 `rejectedAttempts`，向后兼容（缺省按 0）；无需迁移。
