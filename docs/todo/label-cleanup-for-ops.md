## 残留项（按影响面排序）

### 1. 类型分裂：同一 labelId 新旧两形态并存（影响最大）

清理保留了正确的标签 id，但**存量岗位的字段类型没刷**——同一 labelId 一部分岗是新的
单选/多选、大部分岗还是旧 TEXT。AI 按 labelId 跨岗复用答案时，TEXT 岗的自由文本
塞不进单选岗的选项集（0818 清单 §一-8 点过名的问题，现扩散到 7 个标签）：

| labelId | 标题 | 类型分布 | TEXT 存量集中在 |
| --- | --- | --- | --- |
| 300 | 每周可出勤天数 | TEXT×127 / 单选×1 | 必胜客 100、肯德基 26 |
| 741 | 每天可工作时间段 | TEXT×167 / 多选×13 / 单选×1 | 必胜客 116、肯德基 44、哈根达斯 7 |
| 744 | 可在岗几个月 | TEXT×88 / 单选×3 | 必胜客 36、肯德基 30、达美乐 18 |
| 703 | 学信网是否在籍 | TEXT×3 / 单选×9 | — |
| 561 | 意向岗位 | TEXT×31 / 单选×4 | — |
| 753 | 有无工作经验 | TEXT×15 / 单选×2 | — |
| 560 | 意向班次 | 多选×5 / 单选×3 | — |

**要做**：把 TEXT 存量岗批量刷成该标签的规范形态（类型全库唯一，契约建议 P2 同款诉求）。
