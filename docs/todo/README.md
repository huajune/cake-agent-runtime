## 维护规则

1. 新 todo 必须写清所有者、当前状态与可验证的完成条件。
2. “以后也许做”但没有触发条件的想法不进本目录。
3. 落地后先更新架构/产品/数据库现状文档，再删除 todo；明确标注为实施对账单的文档，必须保留到
   用户完成对账并明确授权归档或删除。
4. 生产观察项完成后把数字写入 release note，不把 todo 改造成永久复盘。
