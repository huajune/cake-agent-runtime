> **日期**：2026-08-12 · **目的**：定位"教学示例文案引发幻觉"的全部现场，为示教纪律（P12 候选）提供数据基础。
> **方法**：枚举全部模型可见文本构建器（主提示词 2 份 md、14 个 prompt section、13 个工具描述、抽取提示词、复聊 judge 提示词、group-task 提示词、critical-turn-guard、formatters）并通读；标记 grep（例如/如/示例/这类/→）仅作初筛。剔除纯代码注释后，模型可见示例实例约 **130 处**。
> **⚠️ 方法论教训（写给下次普查）**：标记法两处失灵——turn-hints 的示例标记是 `"……"这类句子`（「这类」不在初版模式）；14 个 section 初版只扫了 4 个。普查完备性以"枚举构建器并通读"为准。

## 分类框架

| 机制 | 定义 |
|---|---|
| M1 示例值→数据 | 虚构/具体值被模型当事实检索（真值缺席时示例引力最强） |
| M2 教学语→输出 | 元语言（模板/示例/内部机制表述）漏进候选人可见文本 |
| M3 格式骨架→臆造 | 格式教学=无数据也能实例化的生成器 |

| 值类型 | 定义 | 风险基线 |
|---|---|---|
| V-fab | 虚构人身值（人名/门店名/号码） | 最高 |
| V-num | 具体数字嵌在教学文案（薪资/距离/时段） | 高（出站方向） |
| V-format | 格式骨架（日期格式/表单行） | 中（M3） |
| V-real | 真值域（真实城市/品牌/枚举/标签名/地理通识） | 低 |
| V-utter | 话语类示例（教识别的候选人语句/教说的话术模板） | 低 |
| V-meta | 元词（模板/示例/内部说明） | M2 敏感 |
