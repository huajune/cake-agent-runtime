# 出站守卫裁决链（确定性规则 → 有界收敛）

Output 是 Input / Prompt / Tool / Output 四个作用位中的最终出站验收。它不再调用第二个模型
复审主 Agent，只处理可复算信号。

```text
候选回复
  → 精确长段落去重
  → Hard Rules：19 个 ruleId（14 执行档 + 5 observe 哨兵）
  → pass | observe | revise | block
      ├─ pass / observe → 继续
      └─ revise / block → 机械最小修复或 ReplyRepairAgent（最多一次）
                          → 同一规则二审 → repair regression gate → 收敛
  → OutboundReplySanitizer
  → TurnOutcome：reply | guardrail_blocked | handoff | skipped
```

## 规则边界

当前规则只含：

- 模型格式异常、内部实现泄漏、元叙述旁白；
- 身份/经历造假教唆、歧视性筛选、籍贯探问、名额承诺等封闭高风险词形；
- booking/改约/线上面试位置、明确 no-match 门店状态、高置信品牌回指等工具回执对账。

一般岗位事实、承诺质量、重复语义和候选人不满意程度由主 Agent 理解，不用正则或第二模型
评分。精确重复由 sanitizer 机械删除；handoff 承诺由 TurnOutcome 与实际副作用对账。

## 有界修复

1. 优先剥围栏、推理残文或 JSON 信封等可机械删除内容；
2. 其余交给无工具的 `ReplyRepairAgent` 做局部修改；
3. hard cap 一次，修复后再过相同确定性规则；
4. regression gate 防结构、极性、日期和既成 booking 状态退化；
5. 高风险仍失败则 `guardrail_blocked/outbound`，可恢复低风险残留按既有规则留档 fail-open。

`replan` 已退役；repair 不能重进 Generator、重调工具或重复副作用。

## 记录面

- `guardrail_review_records`：有规则信号回合的首版、修复版与裁决；历史
  `semantic_reviews` 仅为存量字段；
- `message_processing_records.guardrail_output`：流水摘要；
- 最终投递质量审计看 `reply_preview` 与工具回执。
