# 生产实践经验（principles/）

本目录（principles/）收录 **Agent 生产实践的经验总结**——从真实事故、观测数据与全库普查中蒸馏出来、跨单一功能域、对未来设计有约束力的原则性文档。

## 与相邻目录的分工

| 目录 | 回答的问题 | 文档性质 |
|---|---|---|
| `architecture/` | 系统**现在**长什么样 | 纯现状，随代码刷新 |
| `todo/` | 接下来**做什么** | 执行清单，做完归档 |
| **`principles/`（本目录）** | 我们**学到了什么、以后按什么原则设计** | 经验蒸馏，随裁定演进、极少作废 |

## 收录标准（三条都满足才进来）

1. **事故实证**：结论由生产 badcase / 观测数据支撑，不是理论推演；
2. **跨域约束力**：不止指导一个模块，能作为后续设计的判据被其他文档引用；
3. **已经裁定**：经过辩论收敛、用户拍板，不是待讨论的提案（提案去 `todo/` 或 `product/`）。

## 目录

- **[prompt-example-hygiene.md](./prompt-example-hygiene.md)** ⭐ — 示例示教与幻觉：教学示例引发幻觉的三机制、全库示例面普查（约 130 处）、2026-08 业界解法对照、示教四原则。

## 写作规范

- 结论必须带**事故/数据编号**（badcase id、观测日期、普查数字）——本目录的权威性全部来自实证；
- 原则被推翻或修订时**划线保留原文并标注日期**（参照 rules-vs-semantics P9/P2/P4 的修订体例），演进史本身就是经验；
- 每篇附"配套现状文档"与"执行清单"链接，读者能从原则跳到现状与行动。
