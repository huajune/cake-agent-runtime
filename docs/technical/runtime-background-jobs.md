# 后台作业可靠执行（阶段六）

## 已接入的入口

- `infra/queue/RedisLeaseService` 统一持有者令牌、Lua 原子续期/释放、有限等待。消息聚合、托管到期、带外对账扫描、岗位体检、群发账号锁已迁移。Redis 异常时告警并停止当前工作，不能降级为无锁执行。
- `conversationProcessingLeaseKey(chatId)` 保持原 `wecom:message:lock:{chatId}` 字节格式，正常回合和后台补账共用。环境前缀仍由 RedisService 添加。
- `CronRunnerService` 接管运营日报、海绵状态轮询、聊天同步及六个群任务定时入口。开始/完成/失败写 Redis 生命周期记录，保留 90 天。每次下一页、下一批外部写前检查预算并验证持有者。已有在途 HTTP 请求等待结束，不用超时竞速提前释放锁。
- 启动检查这些定时任务最后观察时间；首次安装只建立基线，以后错过轮次告警，不自动补跑。群任务仅在生产检查，保留各自工作日规则。
- 所有 Bull 连接分支共用默认参数、锁续期/卡死配置；现有业务重试次数和保留数量继续由共享配置 profile 指定。消息聚合、群任务、记忆沉淀及新增恢复队列统一重试耗尽告警。

## 关键写入恢复

| 入口 | 正常路径 | 失败后的处理 |
| --- | --- | --- |
| 报名成功、取消、改约、面试通过事件 | 等待原数据库幂等写入 | `critical-ops-events` 保存原业务键和发生时间，最多 5 次指数退避。只补事件，不再报名/取消/改约。 |
| 报名失败暂停托管 | 等待暂停结果 | 卡片仅在确认成功时写已暂停，其余明确暂停失败或未确认。 |
| 飞书介入任务 | `intervention-tasks` 先入队，再准备不可变请求并保存发出标记 | 准备阶段可重试；已有发出标记却无 taskGuid 视为结果未知，保留失败任务并告警人工核对，不自动重复创建。 |
| 复聊/面试提醒排程与撤销 | `reengagement-commands` 先持久化命令，消费者调用原领域调度器 | 队列或撤销失败抛出重试；撤销冻结锚点截止时间，旧命令不能撤掉更晚的新任务。 |
| 候选人活跃时间 | 等待原子最大时间写入 | 写失败入命令队列补记，迟到恢复不能把较新的活跃水位改旧。 |

新增关键队列完成记录保留 7 天/最多 1000 条；失败记录不自动删除。已耗尽任务须先核对原因再人工重试。飞书未知任务应先按任务内容、clientToken 和发出时间查证实际结果，确认已有任务时补 taskGuid；不能仅清除 dispatchStartedAt 后盲重试。本阶段没有新增执行上述运维操作的 HTTP 接口。

当数据库与恢复队列同时不可用时，记录 `ops.critical_event_not_durable`；这不构成持久化成功。外部成功后的跨存储补账由阶段三 action 记录接续。阶段六没有提供跨 PostgreSQL、Redis、飞书的原子事务，也没有把未知结果伪装成失败后可重发。

## 预算与边界

- 日报：10 分钟、200 行；聊天同步：10 分钟、1000 个会话，已有飞书记录索引最多 10000 行，超限停止而非拿不完整索引继续创建。外部写每批最多 100 行并重检预算。部分写失败按失败生命周期处理，不自动补跑整轮。
- 海绵状态轮询：每轮最多一页 100 条报名事件、10 分钟；Redis 保存页游标，最后一页归零。每企业只按本页精确 `idempotency_key` 查询通过事件，使用既有 `(corp_id,event_name,idempotency_key)` 唯一索引。尚未到当前页的工单将在后续轮次检查，不能把本轮 100 条当作整个窗口。
- 轮询使用 `(report_date,id)` seek 游标和仅报名事件的部分索引；企业内通过事件复用既有唯一索引。已在隔离 PostgreSQL 的 60 万条合成事件上验证，见 [EXPLAIN 记录](runtime-background-jobs-explain.md)。新索引迁移未执行到生产。
- 其他统计/维护 cron 暂未纳入包装。工具的普通报名/取消卡片、群邀请告警卡片也不属于飞书任务队列；前者的外部 action 记录由阶段三覆盖，群满/拒邀等安全告警仍保留原有保障，尚未纳入动作账。
- lease 是有限期协调机制，不能撤销已发出的远端请求；丢租约后下一次写前必须停止，不能把续期失败当作继续执行的许可。

## 验证与发布边界

本地验证包括 owner 不符/过期/Redis 故障、锁等待上限、cron 预算及未知执行不能提前释放锁、业务事件失败后恢复、飞书成功后本地保存失败不重建任务、排程失败重试、真实暂停状态卡片、三种 Redis 连接配置一致以及完整模块依赖装配。测试使用 mock，不向真实业务系统写入。

本阶段不切换阶段四/五生产开关，不运行生产迁移，不自动重放历史失败任务。上线后观察队列失败、租约丢失、cron 未执行告警及轮询游标推进，再按实际数据量调整预算。
